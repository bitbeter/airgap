# PRD ۱۰ — قالب‌بندی و اعتبارسنجی JSON

مسیر: `#/json-format` · عنوان: «قالب‌بندی JSON» · آیکون: `Braces`

## هدف
قالب‌بندی، فشرده‌سازی و اعتبارسنجی JSON بدون چسباندن داده در سایت‌های آنلاین.

## دامنه
1. قالب‌بندی با تورفتگی ۲/۴/تب، فشرده‌سازی، مرتب‌سازی کلیدها (بازگشتی، اختیاری).
2. پیام خطای فارسی با شمارهٔ خط و ستون و نمایش خط خطادار؛ کلیک روی خطا مکان‌نما را به آن نقطه ببرد.
3. حالت «JSON با کامنت/ویرگول انتهایی» (JSONC، اختیاری) برای خواندن؛ خروجی JSON استاندارد.
4. نمای درختی جمع‌شونده با مسیر هر گره (`$.users[2].name`) و کپی مسیر/مقدار.
5. آمار: اندازه، تعداد کلیدها، عمق.

## خارج از دامنه
JSON Schema، تبدیل به YAML/CSV (می‌تواند PRD بعدی باشد)، jq.

## نیازمندی‌ها
- ناحیهٔ کد `dir="ltr"`؛ صفحه RTL.
- اعداد بزرگ: هشدار وقتی عددی از `Number.MAX_SAFE_INTEGER` بزرگ‌تر است چون `JSON.parse` دقت را از دست می‌دهد؛ در حالت قالب‌بندی متن اصلی عدد حفظ شود (پارسر توکنی سبک یا قالب‌بندی مبتنی بر توکن، نه parse/stringify).
- ورودی بیش از ۱ مگابایت در worker پردازش شود با لغو.
- آخرین ورودی ذخیره نشود (ممکن است محرمانه باشد)؛ فقط تنظیمات در `airgap:json-format:settings:v1`.

## پیاده‌سازی و فایل‌ها
- `lib/tokenize.mjs`، `lib/format.mjs`، `lib/locate-error.mjs` (+ `.d.mts`).
- `components/json-tree.tsx`، `json.worker.ts`، `hooks/use-json-format.ts`.

## معیار پذیرش
- `12345678901234567890` در خروجی قالب‌بندی بدون تغییر می‌ماند.
- قالب‌بندی رشته‌های فارسی و escapeها را حفظ می‌کند.
- خطای ویرگول اضافه، کوتیشن جاافتاده و براکت بسته‌نشده با خط/ستون درست گزارش می‌شوند.

## تست
`tests/format.test.mjs`، `tests/locate-error.test.mjs`: مقایسه با `JSON.stringify(JSON.parse(x), null, n)` برای ورودی‌های امن، اعداد بزرگ، JSONC.
