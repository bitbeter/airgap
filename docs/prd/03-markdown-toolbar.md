# PRD ۳ — نوار ابزار، میانبرها و آمار ویرایشگر Markdown

## هدف
نوشتن Markdown برای کاربری که نحو آن را از حفظ نیست ساده شود، بدون از دست رفتن سادگی textarea.

## دامنه
1. نوار ابزار بالای ویرایشگر: تیتر (۱–۳)، پررنگ، ایتالیک، خط‌خورده، کد درون‌خطی، بلوک کد، لینک، فهرست نقطه‌ای، فهرست شماره‌دار، چک‌لیست، نقل‌قول، جدول ۳×۳، خط جداکننده، قالب Mermaid (flowchart نمونه).
2. میانبرها: `Ctrl/⌘+B` پررنگ، `Ctrl/⌘+I` ایتالیک، `Ctrl/⌘+K` لینک، `Tab`/`Shift+Tab` تورفتگی فهرست (فقط وقتی مکان‌نما داخل آیتم فهرست است؛ در غیر این صورت رفتار پیش‌فرض Tab برای دسترس‌پذیری حفظ شود).
3. ادامهٔ خودکار فهرست با Enter و حذف نشانهٔ خالی با Enter دوم.
4. آمار زیر ویرایشگر با اعداد فارسی: کلمات، نویسه‌ها، خطوط، زمان تقریبی مطالعه.
5. عملیات روی متن انتخاب‌شده کار کند؛ بدون انتخاب، نشانه درج و مکان‌نما بین آن‌ها قرار گیرد. اعمال دوباره، قالب را بردارد (toggle) برای پررنگ/ایتالیک/کد.

## خارج از دامنه
ویرایشگر WYSIWYG، کتابخانهٔ ویرایشگر کد (CodeMirror/Monaco)، چند سند.

## نیازمندی‌ها
- تغییرات از مسیر `updateText` فعلی بگذرند تا ذخیرهٔ فوری حفظ شود.
- Undo مرورگر تا حد امکان کار کند: درج با `document.execCommand("insertText")` در صورت پشتیبانی و fallback به `setRangeText`. این محدودیت در README ثبت شود.
- شمارش کلمات با `Intl.Segmenter` (granularity: word) تا فارسی و ZWNJ درست شمرده شوند.

## رابط کاربری
- دکمه‌ها `size="sm"` و `variant="ghost"` با آیکون Lucide، `aria-label` و `title` فارسی همراه میانبر.
- `role="toolbar"` با پیمایش جهت‌دار؛ ترتیب منطقی در RTL.
- در موبایل نوار افقی اسکرول بخورد.

## داده و ذخیره‌سازی
بدون کلید جدید.

## پیاده‌سازی و فایل‌ها
- `lib/format.mjs` + `.d.mts`: توابع خالص `(text, selectionStart, selectionEnd) => { text, selectionStart, selectionEnd }` برای هر عمل.
- `lib/stats.mjs` + `.d.mts`
- `components/toolbar.tsx`، به‌روزرسانی `page.tsx`.

## معیار پذیرش
- هر عمل روی انتخاب خالی، انتخاب یک‌کلمه‌ای، چندخطی و متن فارسی/انگلیسی درست کار می‌کند.
- ذخیرهٔ پیش‌نویس و رفتار پاک‌کردن مثل قبل است.
