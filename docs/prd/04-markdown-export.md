# PRD ۴ — خروجی گرفتن از Markdown

## هدف
متن نوشته‌شده بدون ابزار دیگر قابل تحویل باشد: فایل `.md`، فایل HTML مستقل، و چاپ/PDF راست‌به‌چپ.

## دامنه
1. «دانلود ‎.md» — متن دقیق پیش‌نویس، UTF-8.
2. «دانلود HTML» — یک فایل مستقل با CSS درون‌خطی، `lang="fa" dir="rtl"`، فونت سیستمی، نمودارهای Mermaid به‌صورت SVG درون‌خطی یا `<img>` با data URI. بدون اسکریپت و بدون منبع خارجی.
3. «چاپ / ذخیره به PDF» — `window.print()` با stylesheet چاپی که فقط پیش‌نمایش را با پس‌زمینهٔ روشن و متن تیره چاپ می‌کند (استثنای مجاز از تم دارک، فقط برای کاغذ).
4. «کپی HTML» — کپی محتوای رندرشده به‌صورت `text/html` و `text/plain` با `ClipboardItem` و fallback به متن ساده.
5. نام فایل پیش‌فرض از اولین تیتر سند، پاک‌سازی‌شده؛ در نبود تیتر `document`.

## خارج از دامنه
DOCX، ساخت PDF با کتابخانه، قالب‌های چندگانه.

## نیازمندی‌ها
- HTML خروجی از همان رندر امن صفحه تولید شود (`renderToStaticMarkup` با همان `markdownComponents`، `skipHtml`) تا HTML خام کاربر وارد نشود.
- لینک‌ها در خروجی `rel="noopener noreferrer"` داشته باشند.
- تصاویر همچنان placeholder بمانند (هیچ درخواست خارجی).
- کدِ خروجی lazy باشد تا حجم بارگذاری اولیهٔ صفحه زیاد نشود.

## پیاده‌سازی و فایل‌ها
- `lib/export-html.mjs` + `.d.mts`: ساخت سند کامل از HTML بدنه و CSS.
- `lib/filename.mjs`: استخراج و پاک‌سازی نام.
- `components/export-menu.tsx`، `print.css`.

## معیار پذیرش
- فایل HTML بدون اینترنت درست و راست‌به‌چپ باز می‌شود و جهت هر پاراگراف مثل پیش‌نمایش است.
- `<script>` یا منبع `http(s)` در خروجی وجود ندارد (تست).
- پیش‌نمایش چاپ مرورگر فقط محتوای سند را نشان می‌دهد، نه header و ویرایشگر.

## تست
`tests/export.test.mjs`: نبود اسکریپت، حفظ `dir="auto"`، جدول GFM، فرار درست کاراکترها، نام فایل فارسی و نام خالی.

## ریسک‌ها
Mermaid در زمان خروجی باید رندر شده باشد؛ اگر رندر شکست خورد، سورس به‌صورت بلوک کد قرار گیرد.
