# Airgap

وب‌اپ فارسی برای ابزارهای مستقل، با اولین صفحهٔ مقایسهٔ متن.
رابط از کامپوننت‌های shadcn/ui با سبک New York و رنگ Neutral استفاده می‌کند.

## اجرا

```sh
npm install
npm run dev
```

## بررسی و ساخت

```sh
npm test
npm run build
```

محاسبه با کتابخانهٔ jsdiff (بستهٔ `diff`) داخل Web Worker انجام می‌شود. متن‌ها ذخیره یا به سرور ارسال نمی‌شوند.
مبنای تغییرات خطی، `diffLines` و الگوریتم Myers است؛ همان خانوادهٔ الگوریتم پیش‌فرض Git. محاسبهٔ تطبیق بلوک‌ها و تغییرات داخل خط هم با `diffArrays` همین کتابخانه انجام می‌شود و الگوریتم امتیازدهی و ماتریس تطبیق سفارشی نداریم.
خروجی کنارهم است؛ مرز خط‌های مشترک در خروجی مقایسهٔ نویسه‌ای کتابخانه، هم‌ترازی نمایشی را تعیین می‌کند. تغییرات داخل هر خط در سطح نویسهٔ نمایشی (grapheme) مشخص می‌شوند تا ایموجی و حروف ترکیبی شکسته نشوند.
این ابزار خود Git را در مرورگر اجرا نمی‌کند؛ در متن‌های تکراری یا به‌خاطر قواعد جابه‌جایی مرز بلوک‌ها در Git، خروجی می‌تواند متفاوت باشد. تست‌های تطبیقی چند نمونه را با `git diff --no-index --diff-algorithm=myers --no-indent-heuristic` می‌سنجند؛ برای اجرای این تست‌ها Git باید نصب باشد.
خروجی برای متن‌های بلند در صفحه‌های ۲۰۰ ردیفی نمایش داده می‌شود. فاصله، تب، نیم‌فاصله و پایان خط‌های LF/CRLF و نبود خط جدید انتهای متن قابل تشخیص‌اند. نویسه‌های نامرئی تغییرکرده به‌صورت علامت نمایش داده می‌شوند؛ نمایش همهٔ فاصله‌ها نیز قابل فعال‌کردن است.
برای مقایسه‌های بسیار پیچیده، پردازش پس از چهار ثانیه متوقف می‌شود و پیام خطا نمایش داده می‌شود.

کامپوننت‌ها در `src/components/ui` و صفحهٔ اول در `src/App.tsx` قرار دارند.
