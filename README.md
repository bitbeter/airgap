# Airgap

وب‌اپ فارسی برای ابزارهای مستقل، با اولین صفحهٔ مقایسهٔ متن.
رابط از کامپوننت‌های shadcn/ui با سبک New York و رنگ Neutral استفاده می‌کند.

## اجرا

```sh
npm install
npm run dev
```

## بررسی و ساخت

```sh
npm test
npm run build
```

برای تست‌های تطبیقی diff، نصب Git لازم است.

## ساختار و توسعه با ایجنت

- هر قابلیت مستقل در `src/features/<name>/` قرار دارد؛ صفحه، منطق، کامپوننت‌ها، worker و تست‌های همان قابلیت در این پوشه هستند.
- پوسته و مسیریابی در `src/app/` هستند. برای افزودن صفحه فقط آن را در `src/app/features.ts` ثبت کنید؛ منو خودکار از همین فهرست ساخته می‌شود.
- کامپوننت‌های مشترک shadcn در `src/components/ui/` و ابزارهای مشترک در `src/lib/` قرار دارند.
- صفحات با مسیر مستقل مثل `#/text-diff` و بارگذاری جداگانه باز می‌شوند. نیازی به تغییر صفحهٔ diff برای اضافه‌کردن ابزار جدید نیست.

از [راهنمای ایجنت](AGENTS.md)، [معماری پروژه](docs/architecture.md) و [راهنمای افزودن قابلیت همراه پرامپت نمونه](docs/adding-a-feature.md) شروع کنید.

## مقایسهٔ متن

صفحهٔ مستقل `src/features/text-diff/page.tsx` مقایسهٔ کنارهم با نمایش تغییرات داخل خط، کپی ورودی‌ها، و تاریخچهٔ سه مقایسهٔ آخر در localStorage را فراهم می‌کند. محاسبه با jsdiff در Web Worker انجام می‌شود؛ متن‌ها به سرور ارسال نمی‌شوند.

جزئیات رفتار، فایل‌ها و قرارداد ذخیره‌سازی در [راهنمای قابلیت diff](src/features/text-diff/README.md) آمده است.
